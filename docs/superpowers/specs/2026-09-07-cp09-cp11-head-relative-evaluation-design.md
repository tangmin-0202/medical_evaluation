# CP09/CP11 头模相对坐标评价设计

## 目标与范围

本设计只调整 CP09 和 CP11 的视觉证据提取及确定性判定，不改动评分权重、Qwen 权限边界、其他考核点或现有网页报告结构。

运行时不再依赖每个视频人工标注口腔框或鼻部框。三个样本使用同型号牙科训练头模，因此可用头模建立稳定的相对坐标系，并用一套经过正确样本校准的标准位置作为后备参考。

实施顺序必须是：先在服务器真实视频上验证头模和鼻子的 SAM3 文本提示，再修改生产管线。提示验证失败时先汇报真实掩膜问题并调整提示或识别边界，不用人工标注伪装自动识别成功。

## 保持不变的边界

- SAM3 只产生对象掩膜和时间证据。
- Judge 仍是状态、原因码和分数的唯一来源。
- Qwen 只能解释 Judge 结果，不能修改状态、原因码或分数。
- SAM2 保留为可选后端；本设计首先在 SAM3 后端实现和验收。
- 最终成绩在 11 项完成前仍为 `null`，页面继续显示阶段性成绩和已评估项数。

## 第一阶段：文本提示可行性门槛

### 测试对象

在 success、failure、clamp_failure 三个真实视频的 CP09 和 CP11 代表帧上分别测试以下语义目标：

- 头模候选提示：
  - `dental training mannequin head`
  - `plastic dental mannequin face`
  - `dental mannequin head and face`
- 鼻部候选提示：
  - `nose of the dental mannequin`
  - `plastic nose on the dental mannequin face`
  - `mannequin nose`

候选文本是有边界的实验集合。根据三视频真实掩膜选择一个头模提示和一个鼻部提示，并把最终文本、输出阈值、采样时间、模型版本和证据图写入审计记录。

### 验收条件

头模提示必须满足：

- 在三个视频的目标阶段能找到头模；
- 掩膜覆盖训练头模的头面部主体，不把操作者、手套或背景作为主体；
- 连续帧轮廓足以建立位置、尺度和方向参考。

鼻部提示必须满足：

- 在 CP11 最终候选窗口内能找到头模鼻部；
- 不把操作者的手指、牙齿、夹子或背景结构作为鼻部；
- 连续有效帧足以计算鼻部与橡皮布的重叠率。

测试需保存原图、掩膜和叠加图并目视检查。单帧成功不能通过门槛。若文本提示在任一样本上不稳定，应先尝试候选文本和合理输出阈值；仍失败时停止生产实现并汇报失败类型。

### 多对象会话

优先验证锁定 SAM3.1 multiplex API 能否在同一采样序列和会话中维护多个文本目标。若官方接口能稳定区分对象，CP09 共同追踪头模与支架，CP11 共同追踪头模、鼻子与橡皮布。若锁定接口不能保证对象身份，则复用同一模型实例和抽帧序列、为各对象建立独立会话；不得为了减少调用次数牺牲对象一致性。

## 头模坐标系

对每个有效头模掩膜保留最大连通主体，计算稳健中心、尺度和主方向。将支架、鼻部和橡皮布的图像坐标转换到头模局部坐标：

- 横向位置以头模宽度归一化；
- 纵向位置以头模高度归一化；
- 角度以头模主方向为零点，并按 180 度周期计算差值。

头模轮廓被手部遮挡、严重出画或主方向跳变时，该帧不进入几何聚合。若有效头模证据不足，返回 `needs_review/unreliable_head_tracking`。

同型号头模允许保存一套版本化的标准支架位置，包括头模局部坐标下的支架中心、角度、尺度和区域模板。初始 Demo 可由 success 样本建立候选模板，但模板在独立样本验证前不得描述为临床阈值或泛化标准。

## 自动稳定窗口

稳定窗口统一由对象相对头模的变化确定，不依赖固定的人工末三秒：

- CP09 使用支架中心、角度和尺度的帧间变化；
- CP11 使用橡皮布相对头模的区域重叠变化及鼻部位置变化；
- 候选窗口必须位于对应阶段后部，并连续稳定至少 2 秒，目标为 2–3 秒；
- 对候选窗口内特征取中位数，并记录离散程度和有效帧数。

模型证据可靠但始终不能形成稳定窗口时属于操作结果失败，而不是模型失败。跟踪证据不足或波动由明显掩膜错误造成时进入人工复核。

## CP09 判定

### 数据流

1. 在 CP09 完整时间段扫描头模和白色 U 形支架。
2. 将每帧支架中心、角度和尺度转换到头模坐标。
3. 自动找到阶段末尾连续 2–3 秒的稳定窗口。
4. 在稳定窗口内计算支架相对标准位置的横向偏移、纵向偏移、角度差和尺度差。
5. 保存头模轮廓、面部中线、目标位置带、支架掩膜及中心连线叠加图。
6. 只要支架轨迹可靠且形成稳定窗口，就保存可审计的头模—支架相对参考供 CP11 使用。即使 CP09 因位置不合格被判为 `incorrect`，实际支架区域仍可用于 CP11 的覆盖判断。

### 状态优先级

1. 头模证据不足：`needs_review/unreliable_head_tracking`。
2. 完整 CP09 内没有可靠、连续的支架证据：`incomplete/frame_not_observed`。
3. 支架出现过但末尾消失或调整后未保持：`incorrect/frame_missing_at_stage_end`。
4. 支架末尾仍存在但没有形成稳定窗口：`incorrect/frame_not_stabilized`。
5. 稳定窗口内中心、角度或尺度不合格：`incorrect/frame_installation_failed`，同时保存具体失败特征。
6. 末尾稳定存在且位置、角度、尺度均合格：`correct/criteria_satisfied`。

“模型没有输出支架”只有在头模、画面质量和阶段扫描均可靠时才能解释为实际未安装；否则必须进入人工复核。

### CP09 特征

- `frame_presence_ratio`
- `frame_valid_count`
- `head_valid_count`
- `final_stable_duration_sec`
- `frame_head_horizontal_offset`
- `frame_head_vertical_offset`
- `frame_head_angle_difference`
- `frame_head_scale_ratio`
- 对应时间序列的稳健离散程度

具体阈值不在首次实现中凭单一样本写死。先输出三视频分布和叠加图，再根据正确样本、明显失败样本和边界样本确定初始 Demo 阈值；阈值附近设置 `needs_review` 灰区。

## CP11 判定

### 数据流

1. 全阶段只判断橡皮布是否出现过，用于区分未完成和已经尝试但最终失败。
2. 在阶段后部追踪头模、鼻部和绿色橡皮布，自动寻找最终稳定窗口。
3. 优先读取本视频 CP09 保存的头模—支架相对参考；不可用时使用同型号头模的版本化标准模板。
4. 根据 CP11 头模姿态将预期支架区域映射到当前帧，不再从 CP09 到 CP11 长程追踪支架。
5. 计算鼻部与橡皮布重叠率、预期支架区域的橡皮布覆盖率，以及预期支架区域内的白色裸露比例。
6. 保存头模、鼻部、橡皮布、预期支架区域和裸露区域叠加图。

删除原来的 `dam_area_ratio` 整帧面积判据。CP11 不评价口部无遮挡，因为口部本应被橡皮布覆盖；只评价鼻部无遮挡和支架被覆盖。

### 状态优先级

1. 头模证据不足：`needs_review/unreliable_head_tracking`。
2. 整个 CP11 没有可靠发现橡皮布：`incomplete/rubber_dam_not_observed`。
3. 橡皮布出现过但末尾消失：`incorrect/rubber_dam_missing_at_end`。
4. 末尾没有形成连续稳定状态：`incorrect/final_state_not_stable`。
5. 鼻部跟踪不可靠：`needs_review/unreliable_nose_tracking`。
6. CP09 参考和标准模板均不可用：`needs_review/frame_reference_unavailable`。
7. 橡皮布明显覆盖鼻部：`incorrect/nose_obstructed`。
8. 预期支架区域覆盖不足或存在明显白色裸露：`incorrect/frame_not_covered`。
9. 支架区域被覆盖且鼻部无遮挡：`correct/criteria_satisfied`。

### CP11 特征

- `dam_stage_presence_ratio`
- `dam_final_presence_ratio`
- `head_valid_count`
- `nose_valid_count`
- `dam_valid_count`
- `final_stable_duration_sec`
- `nose_overlap_ratio`
- `expected_frame_dam_coverage_ratio`
- `visible_frame_ratio`

## 三样本预期

- success：CP09 形成稳定、居中的头模—支架参考并判为 `correct`；CP11 鼻部无遮挡且预期支架区域被橡皮布覆盖，判为 `correct`。
- failure：CP09 以真实稳定窗口和头模相对坐标重新判定，不沿用旧 SAM2 数值；CP11 未观察到橡皮布，判为 `incomplete/rubber_dam_not_observed`。
- clamp_failure：CP09 若支架从未可靠出现，判为 `incomplete/frame_not_observed`；若出现后因夹子脱落未能在末尾保持稳定，判为对应 `incorrect` 原因。CP11 未观察到橡皮布时仍判为 `incomplete/rubber_dam_not_observed`。

三个样本的预期用于验证分支覆盖和 Demo 行为，不能作为准确率或泛化结论。若真实证据与上述预期不符，先检查掩膜和阶段边界，再决定是实现错误、提示失败还是规则假设错误，不为了匹配标签修改 Judge。

## 持久化与审计

每次任务保存：

- 最终采用的文本提示、阈值和 SAM3 版本；
- 每条轨迹的有效帧数、耗时和显存峰值；
- 稳定窗口起止时间及判定依据；
- 头模局部坐标变换参数；
- CP09 头模—支架参考及其来源；
- CP11 使用本视频参考或标准模板的标记；
- 原始掩膜、特征时间序列、代表性叠加图、Judge 原因码和 Qwen 来源。

## 测试与验收

1. 为头模坐标变换、角度周期、稳定窗口、模板映射和状态优先级编写失败测试。
2. 扩展 SAM3 契约测试，覆盖多文本目标或独立会话后备路径、对象缺席空掩膜和会话释放。
3. 跑相关聚焦测试、完整 pytest 和 Ruff。
4. 在服务器 GPU 6 上先做头模/鼻部 prompt smoke，并目视检查三个视频代表帧。
5. prompt 门槛通过后运行 success 完整 CP09/CP11，再依次运行 failure 和 clamp_failure。
6. 比较三样本的掩膜、稳定窗口、特征、Judge 状态和原因码；边界结果必须保留原始数值。
7. 恢复 Qwen 点评，验证严格 JSON Schema、证据引用、阶段性分数和 `final_score=null`。
8. 验证网页报告能加载全部证据，并明确显示已评估项数和非最终成绩。

## 已知限制

- 单一正确样本只能建立 Demo 模板，不能确定严谨阈值。
- 头模掩膜主方向可能受手部遮挡和裁切影响，必须设置质量门。
- 鼻部是小目标，文本分割能否在三个视频稳定工作必须由第一阶段实验决定。
- CP09 与 CP11 的自动时间定位仍局限在人工给定阶段内部；完整视频自动分段属于后续任务。
- 同型号头模的模板不能直接推广到不同设备、真实患者或不同拍摄协议。
