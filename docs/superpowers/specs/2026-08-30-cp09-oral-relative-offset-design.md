# CP09 支架相对口腔偏移设计

## 目标

将 CP09 的判定依据从“橡皮障支架相对整幅画面是否居中”改为“橡皮障支架相对整个口腔区域是否居中”。SAM2 在同一阶段内同时分割并跟踪 `rubber_dam_frame` 和 `oral_region`，特征提取器只在两个目标均有效的配对帧上计算相对偏移，并使用阶段中位数交给现有 CP09 Judge。

本次仍是成功视频 CP09 的纵向切片，不扩展其他十个考核点，不宣称已经实现新视频的自动分段或自动提示。

## 已确认输入

- CP09 时间范围为 `175.0–195.0` 秒。
- `rubber_dam_frame` 使用阶段内同一帧的三个正点提示。
- `oral_region` 使用一个框提示，时间为 `174.686926` 秒。
- 口腔提示比阶段起点早约 `0.313` 秒，属于播放器取帧误差；阶段提示筛选允许前后各 `0.5` 秒容差。
- `oral_region` 必须作为第二个 SAM2 目标分割和跟踪，不能仅将标注框作为整段视频中的固定坐标。

## 备选方案与取舍

### 固定口腔框

整段 CP09 复用一次人工框。实现简单，但模型头部或相机移动后参考中心失真，因此不采用。

### 双目标 SAM2 跟踪

在一个阶段窗口内同时提交支架和口腔提示，逐帧得到两套掩膜。它复用已经跑通的 SAM2 视频跟踪后端，能随画面运动更新两个目标的位置，是本次采用的方案。

### 口腔关键点模型

用专门的口腔或面部关键点模型估计口腔中心。长期可能比区域分割更稳，但当前没有相应训练数据和验证集，因此留作后续增强，不进入本次范围。

## 数据流

```text
success.json
  ├─ rubber_dam_frame：三个点
  └─ oral_region：一个框
          ↓
按 CP09 窗口抽取连续 JPEG 帧，并保留边界容差内的提示帧
          ↓
SAM2 在同一推理状态中初始化两个 object_id
          ↓
逐帧输出 rubber_dam_frame mask 与 oral_region mask
          ↓
筛选两套掩膜均非空的配对帧
          ↓
计算逐帧支架相对口腔偏移
          ↓
中位数聚合、规则判断、掩膜与叠加图审计
```

## 提示筛选

`prompts_for_object` 增加可选的 `boundary_tolerance_sec` 参数，默认值保持 `0.0`，避免改变其他调用者行为。CP09 为两个对象显式传入 `0.5`。

允许的提示时间范围为：

```text
[time_range.start_sec - 0.5, time_range.end_sec + 0.5]
```

提示时间仍必须位于视频本身范围内。若任一对象没有满足条件的提示，提取器在启动 SAM2 前失败，错误信息包含视频 ID、考核点、对象名和允许范围。

## 双目标分割

CP09 提取器分别读取 `rubber_dam_frame` 与 `oral_region` 提示，再合并为同一次 `VideoSegmenter.track` 调用。现有 `Sam2Backend` 已按 `object_id` 管理多目标提示，因此不新增第二次视频解码和第二个 SAM2 推理状态。

每个 `FrameMasks` 可以包含：

```text
{
  "rubber_dam_frame": <bool mask>,
  "oral_region": <bool mask>
}
```

单个目标缺失的帧不参与相对偏移计算，但分别计入目标有效帧统计，便于区分“支架丢失”“口腔丢失”和“两者都有效”。

## 相对偏移定义

支架为中空杆状结构，继续使用掩膜外接框中心，而不是白色像素质心。口腔区域同样使用外接框中心，并使用口腔外接框宽、高作为归一化尺度。

对于一对同尺寸掩膜：

```text
(fx, fy) = rubber_dam_frame 外接框中心
(ox, oy) = oral_region 外接框中心
ow       = oral_region 外接框宽度
oh       = oral_region 外接框高度

dx = (fx - ox) / ow
dy = (fy - oy) / oh
oral_relative_offset = sqrt(dx² + dy²)
```

外接框宽高按包含端点的像素数计算，即 `max - min + 1`。若任一掩膜为空、尺寸不一致，或者口腔框宽高无效，则该帧偏移为缺失。

区间特征为全部配对有效帧偏移的中位数：

```text
frame_oral_center_offset = median(per_frame_oral_relative_offset)
```

中位数降低手部短时遮挡、掩膜边缘抖动和个别传播失败的影响。

## 输出特征与兼容策略

CP09 新特征为：

```text
frame_oral_center_offset
frame_valid_count
oral_region_valid_count
paired_valid_count
```

现有 `frame_center_offset` 不再作为 CP09 正误判断依据。Judge 与规则配置在同一变更中显式改为读取 `frame_oral_center_offset`，旧字段从新提取结果中移除。

只有 `paired_valid_count >= 3` 时才生成确定性的阶段偏移。少于三帧时 `frame_oral_center_offset=None`，Judge 输出 `needs_review`，不能把证据缺失当成错误或正确。

阈值暂不根据单个成功视频宣称为临床标准。第一步沿用现有 CP09 阈值作为工程验收起点，但阈值含义改为相对口腔尺度；成功视频和两个失败视频跑完后，再单独设计阈值校准规格。

## 证据产物

代表性证据仍从配对有效帧的前、中、后位置各取一帧。每个证据时刻写出：

- `cp_09/masks/rubber_dam_frame/<frame>.png`
- `cp_09/masks/oral_region/<frame>.png`
- `cp_09/overlays/<frame>.jpg`

叠加图同时显示两个稳定颜色的掩膜和对象名称。`EvidenceItem.rule` 改为 `rubber_dam_frame_relative_to_oral_region`。

烟雾测试 `summary.json` 与 `decision.json` 使用新特征名，并记录两个对象的提示数量。

## 错误处理

- 缺少任一对象提示：在模型加载前失败并指出缺失对象。
- 只有一个目标产生掩膜：保留各自有效帧计数，但相对偏移缺失。
- 两个掩膜尺寸不同：视为契约错误并明确失败，不自动缩放掩膜。
- 配对有效帧少于三帧：输出 `needs_review`。
- `oral_region` 明显跟踪错误：由黑白掩膜和双目标叠加图人工审查。
- 边界提示超出 `±0.5` 秒：不自动扩大窗口，要求修正标注。

## 测试策略

### 纯几何测试

- 两个已知外接框中心重合时相对偏移为零。
- 支架相对口腔水平移动半个口腔宽度时偏移为 `0.5`。
- 垂直与二维组合偏移符合公式。
- 任一掩膜为空、尺寸不一致时行为明确。

### 提示筛选测试

- 默认零容差维持现有严格区间行为。
- `174.686926` 秒提示在起点 `175.0` 秒和 `0.5` 秒容差下被接受。
- 超过容差的提示仍被拒绝，错误包含允许范围。

### CP09 提取器测试

- 一次 track 调用同时包含两个 object_id。
- 只在双掩膜配对有效帧上计算相对偏移。
- 分别输出三个有效帧计数。
- 配对帧少于三帧时保留证据但返回缺失特征。
- 每个代表帧写出两张独立掩膜和一张双目标叠加图。

### Judge 与烟雾测试

- Judge 只读取 `frame_oral_center_offset`。
- 缺失新特征时输出 `needs_review`。
- 烟雾摘要记录新特征和两个对象提示数量。
- CPU 测试不需要安装 SAM2 或 CUDA。

### GPU 验收

在服务器 GPU 7 上重新运行成功视频 CP09。验收条件为：

- 命令退出码为零且不发生整视频显存加载；
- 支架与口腔两个对象均有至少三帧有效掩膜；
- 人工查看前、中、后三张双目标叠加图，确认两套掩膜语义正确；
- `decision.json` 使用 `frame_oral_center_offset`；
- 当前结果只证明成功样本链路成立，不能据此宣称三视频准确率。

## 不包含

- 自动检测口腔或自动生成 SAM 提示；
- CP09 阈值的临床标定；
- 两个失败视频的自动提示修复；
- 其他十个考核点；
- 自动阶段定位、总分或 LLM 点评；
- SAM3 接入或 SAM2/SAM3 对比实验。
