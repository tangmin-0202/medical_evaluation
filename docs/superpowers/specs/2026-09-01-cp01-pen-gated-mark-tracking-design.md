# CP01 笔接触门控与新增黑点跟踪设计

## 目标与已确认规则

CP01 判断学员是否在橡皮布上完成目标牙位标记。白色打孔模板位于橡皮布下方，模板文字、十字线和预制孔会透过橡皮布形成大量稳定暗点，因此不能再把“橡皮布内所有稳定黑点”直接视为学员标记。

本设计覆盖此前与之冲突的 CP01 候选选择规则：

- 先以标记笔与橡皮布是否发生稳定二维掩膜重叠，判断标记动作是否发生；
- 重叠发生前的稳定暗点作为模板背景，不参与学员点候选；
- 重叠发生后持续跟踪新增或明显加深的暗点；
- 阶段结束后按局部黑度保留最黑的 1–2 个稳定新增点；
- 计算这 1–2 个候选与固定正确点在橡皮布局部坐标中的距离，距离最小者作为学员标注点；
- 再使用该最小距离与 CP01 评分阈值比较，决定 `correct` 或 `incorrect`。

固定正确点允许参与最终候选选择，这是本次用户明确确认的规则，并覆盖此前“固定点不得参与候选身份选择”的约束。

## 标注契约

每个实际执行 CP01 的视频在自己的 CP01 时间段内提供：

1. 一个紧密覆盖完整橡皮布的 `rubber_dam` 框；
2. 一个紧密覆盖标记笔笔杆和笔尖的 `marking_pen` 框，选择笔正在橡皮布上标记且遮挡尽量少的清晰帧。

`success` 标准视频另外保留一次性的 `cp01_reference` 点。该点与同帧 `rubber_dam` 框换算后持久化为固定 `(reference_u, reference_v)`，不要求在其他学员视频重复标注。

如果人工真值明确表明 CP01 完全未执行，则不伪造 `marking_pen` 提示。该标注契约把“有一个笔框”解释为该阶段出现过标记笔，把“没有笔框”解释为未观察到标记笔；提取器此时只跟踪橡皮布，输出笔有效帧数和接触证据为零，由 Judge 返回 `incomplete`，不能仅因缺少提示而崩溃。

## 坐标系与跟踪

存在 `marking_pen` 框时，SAM2 在 CP01 完整时间段内同时跟踪 `rubber_dam` 和 `marking_pen`；不存在笔框时只跟踪橡皮布并走缺失路径。每个有效帧必须能够读取画面并获得非空橡皮布掩膜；需要判断笔接触时，还必须获得非空笔掩膜。

所有黑点位置均换算为当前帧橡皮布掩膜外接框的局部坐标：

```text
u = (point_x - dam_left) / dam_width
v = (point_y - dam_top) / dam_height
```

黑点跨帧聚类使用 `(u, v)`，而不是整幅画面像素坐标。橡皮布平移或缩放时，同一个点仍可归入同一轨迹。短暂被手、笔或器械遮挡不立即删除轨迹；重新出现且局部距离在阈值内时继续累计同一轨迹。

## 笔接触事件

逐帧计算：

```text
pen_dam_overlap_ratio = intersection(marking_pen, rubber_dam) / area(marking_pen)
```

只有重叠比例达到 `min_pen_dam_overlap_ratio`，且至少连续 `min_pen_contact_frames` 个有效帧，才确认发生标记动作。单帧擦边、压缩噪声或短暂经过不构成接触事件。

状态优先级：

- 阶段画面和橡皮布证据不足：`needs_review`；
- 有足够有效帧，但全阶段没有稳定笔与橡皮布重叠：`incomplete`；
- 检测到稳定接触：进入新增黑点分析。

二维重叠只能表达视频画面中的接触证据，不声称恢复真实三维接触力。

## 接触前背景与接触后新增点

第一次稳定接触事件之前的有效帧用于建立背景暗点轨迹。模板文字、十字线和预制孔只要在接触前已经稳定出现，就标记为 `preexisting`。

从第一次稳定接触开始直到 CP01 结束，继续检测并跟踪暗点。候选必须满足以下任一条件：

1. 接触前没有对应轨迹，接触后新增并稳定存在；
2. 接触前存在对应较浅轨迹，但接触后局部黑度相对背景显著增加。

局部黑度使用候选区域与其周围橡皮布环形邻域的亮度差，而不是直接比较整幅画面的绝对亮度：

```text
local_darkness = median(local_background_value) - median(candidate_value)
```

这样可减弱画面上亮下暗、阴影和曝光变化的影响。面积过大的手部阴影、细长十字线、文字连通块和只出现一帧的噪声继续被过滤。

## 候选排序与评分

阶段结束后只处理稳定的 `new_or_darkened` 轨迹：

1. 按跨帧局部黑度中位数从高到低排序；
2. 保留最黑的 1–2 个候选；
3. 计算每个候选到固定正确点的局部欧氏距离；
4. 距离最小的候选作为学员标注点；
5. 最小距离不超过 `max_mark_distance` 时为 `correct`，否则为 `incorrect`。

稳定接触已经发生但没有得到任何稳定新增或加深暗点时，表示动作有尝试但未留下可判定标记，返回 `incorrect`。如果缺失来自遮挡、分割中断或可读帧不足，则返回 `needs_review`，不能强行判错。

## 特征与证据

提取器输出至少包括：

- `pen_valid_frame_count`；
- `pen_dam_overlap_ratio`；
- `pen_contact_frame_count`；
- `pen_contact_detected`；
- `preexisting_mark_candidate_count`；
- `new_mark_candidate_count`；
- `selected_mark_u`、`selected_mark_v`；
- `selected_mark_darkness`；
- `mark_reference_distance`；
- `dam_valid_frame_count`。

最多保存三类证据图：

1. 接触事件图：橡皮布轮廓、笔掩膜、重叠区域和重叠比例；
2. 接触前背景图：标出被排除的模板暗点；
3. 最终选择图：最黑的 1–2 个候选、固定正确点、被选中的学员点和距离连线。

证据 JSON 记录阈值、候选黑度、轨迹首次/末次出现时间和选择原因，便于人工复核。

## 阈值与校准

以下阈值全部放在 `config/rubric.yaml`，不写死在 Judge 中：

- `min_pen_dam_overlap_ratio`；
- `min_pen_contact_frames`；
- `min_mark_observed_frames`；
- `min_new_mark_darkness_delta`；
- 暗点面积、亮度和形状过滤范围；
- `max_mark_distance`。

现有 `calibrate_cp01_detector.py` 调整为诊断工具：一次运行 SAM2 后遍历 CPU 阈值，并输出背景轨迹、新增轨迹、最黑 Top 2、选择结果及叠加图。不能只因某组参数得到两个候选就自动采纳；必须确认两个候选与视频中实际标记一致。

## 测试与验收

自动化测试覆盖：

- 笔未接触橡皮布时为 `incomplete`；
- 单帧擦边不构成稳定接触；
- 接触前模板孔被排除；
- 接触后新增黑点被持续跟踪；
- 原有浅点在接触后明显加深时成为候选；
- 暂时遮挡后重新出现仍属于同一轨迹；
- 最黑 Top 2 中按固定点距离选择学员点；
- 接触后无稳定标记为 `incorrect`；
- 证据不足为 `needs_review`；
- 正确和错误距离分别触发 `correct` 与 `incorrect`。

真实 GPU 验收先使用 `success` 视频：人工确认笔掩膜、橡皮布掩膜、接触帧、背景暗点、最终 Top 2 和被选点语义均正确后，再处理两个失败视频。三个样例只能用于 Demo 校准，不能声称具有医学泛化准确率。
