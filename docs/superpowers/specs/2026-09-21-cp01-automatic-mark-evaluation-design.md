# CP01 自动标记评估设计

## 目标与范围

CP01 判断学员是否使用标记笔在橡皮布上标出白色模板右下象限从上往下第三个黑点对应的位置。本阶段只使用自动视觉输入；已有人工阶段时间仍可用于截取 CP01，但每视频的 `rubber_dam` 框、`marking_pen` 点/框和 `cp01_reference` 点不得作为推理输入。

确定性 Judge 是状态、原因码和分数的唯一来源。SAM3 和 OpenCV 只生成对象掩膜、坐标、轨迹、可靠性和可查看证据。

## 判定顺序

1. 扫描完整 CP01 时间段，自动分割标记笔并做深色、细长外形和跨帧连续性过滤。
2. 阶段扫描可靠但未观察到笔时，立即返回 `incomplete/cp01_not_performed`，不运行白板、配准和墨迹分析。
3. 笔可靠出现后进入结果分析。笔只作为“操作已开始”的门槛；不识别笔尖，不要求笔与橡皮布掩膜重叠。
4. 使用覆盖前清晰白板建立模板坐标，选择右下象限从上往下第三个黑点。
5. 自动分割橡皮布，并将模板目标点持续映射到覆盖后的橡皮布坐标。映射不可靠时返回 `needs_review/unreliable_template_reference`。
6. “笔离开”定义为笔不再遮挡橡皮布标记观察区域，并出现连续稳定、低运动、橡皮布和配准均可靠的后置画面；不要求笔完全离开整幅画面。
7. 将笔出现前的多张清晰帧配准后取中位数作为背景，将笔离开后的多张清晰帧配准后取中位数作为结果画面。
8. 新增标记必须是接触前后同一橡皮布坐标中稳定新增或明显加深/扩大的局部暗色轨迹。模板原有黑点、文字、十字线、阴影、褶皱、遮挡、曝光变化和配准双边缘不得计为新增标记。
9. 笔已出现、后置画面可靠但没有新增标记时，返回 `incorrect/mark_not_observed`。
10. 以模板相邻点间距归一化新增标记到目标点的距离。至少一个可靠新增标记在允许范围内即为 `correct/criteria_satisfied`；额外的第二个非目标标记不扣分；可靠新增标记均偏离目标时返回 `incorrect/mark_position_incorrect`。

## 对象分割与复用边界

复用服务器 `22f6354` 已验证过的 SAM3 文本提示作为起点：

- 白板：`white card under the green sheet`
- 橡皮布：`flat green rubber sheet`
- 标记笔：`black pen held in a gloved hand`

已有 success gate 只证明对象候选可分割，不证明最终语义。正式提取器必须保存原图、掩膜、叠加图和拒绝原因，并在 success、failure、clamp_failure 上分别验证。无新证据时不重复已经失败的替代提示。

旧 `Cp01FeatureExtractor` 依赖人工提示和固定 `reference_u/reference_v`，不得直接接入正式评分。`features/cp01_template.py` 的候选检测、目标点选择、投影和点距函数可以复用，但调用方必须先证明白板方向、布局完整性和配准可靠性。

## 笔出现门槛

笔门槛是第一项实现任务。输出至少包括：

- `stage_scan_reliable`
- `pen_presence_detected`
- `pen_valid_frame_count`
- `pen_max_consecutive_valid_frames`
- `pen_first_seen_sec`
- `pen_last_seen_sec`
- 每帧候选接受或拒绝原因

单帧候选不能构成笔出现。SAM3 非空掩膜还必须通过可见外观和连续性过滤。笔未出现时保留代表性负证据并短路后续计算。

## 白板目标点

在白板清晰且尚未完全被橡皮布覆盖的帧中：

1. 从白板掩膜提取可靠外轮廓和四边形。
2. 透视校正为正视模板图。
3. 检测印刷中心线并确定上下、左右方向。
4. 检测黑点候选，排除文字小笔画、中心线交点和大黑块。
5. 通过完整点阵、相邻间距、圆弧排列和跨帧一致性校验身份。
6. 仅在方向和布局可靠时选择右下象限从上往下第三个点，并计算相邻点距。

发现若干黑点不能自行证明布局完整。

## 笔离开与后置清晰帧

笔在多帧中可靠出现后才允许进入离开状态。后置清晰帧必须同时满足：

- 笔掩膜不再遮挡橡皮布标记观察区域；
- 橡皮布掩膜可靠；
- 目标映射位置跨帧稳定；
- 局部运动、模糊和曝光变化在允许范围内；
- 没有大面积手套或器械遮挡。

单帧笔掩膜丢失不算离开。若到阶段结束仍没有可靠后置画面，返回 `needs_review/post_action_view_occluded`。

## 新增墨迹

背景图和结果图必须先配准到统一橡皮布坐标。先补偿全局亮度变化，再计算局部亮度下降、黑色面积增长和局部环形对比。候选需要满足合理面积、紧凑形状和多帧持续性。

新增墨迹包含两类：

- 基线中不存在、结果图中新出现的暗色紧凑区域；
- 基线中已有模板暗点，但结果图中稳定变黑、扩大或边界改变的区域。

若多个模板点同时产生同方向黑白双边缘，或候选变化与全局曝光一致，则视为配准或光照异常，不得计为墨迹。

## 状态机

```text
阶段扫描不可靠
→ needs_review/unreliable_stage_scan

阶段可靠但笔未出现
→ incomplete/cp01_not_performed

笔出现但没有可靠后置画面
→ needs_review/post_action_view_occluded

白板方向、布局或映射不可靠
→ needs_review/unreliable_template_reference

新增墨迹证据不可靠
→ needs_review/unreliable_new_ink_evidence

后置画面可靠但没有新增标记
→ incorrect/mark_not_observed

有新增标记但均偏离目标
→ incorrect/mark_position_incorrect

至少一个新增标记位于目标允许范围内
→ correct/criteria_satisfied
```

## 证据要求

每次真实运行至少保存：

- 笔扫描的原图、掩膜、叠加图和负证据；
- 覆盖前白板原图、掩膜、校正图、点阵和目标点；
- 橡皮布掩膜与目标映射叠加图；
- 笔出现前背景图；
- 笔离开后结果图；
- 前后差分、新增候选、目标点和距离连线；
- 配准误差、点距、候选轨迹、可靠性和拒绝原因 JSON。

## 实施与验收顺序

1. 先完成自动笔出现门槛和缺失短路。
2. 复用已有白板分割，完成真实模板校正、方向和目标点门槛。
3. 完成目标点到覆盖后橡皮布的可靠映射。
4. 完成笔离开后的清晰帧选择。
5. 完成新增墨迹和距离判定。
6. 聚焦测试和完整回归通过后，在 `.102` 固定 GPU5 MPS 通道运行三视频并目视证据。
7. 三视频门槛稳定后才接入 runtime、正式 Judge、rubric、报告和 6/11 阶段性评分。

三个 Demo 只能证明链路和已覆盖分支可运行，不能称为准确率、泛化性能或临床有效性。
