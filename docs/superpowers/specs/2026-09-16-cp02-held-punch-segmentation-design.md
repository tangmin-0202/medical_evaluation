# CP02 手持打孔器自动分割设计

## 目标

在不使用人工点、人工框或人工标签的前提下，从 CP02 视频阶段中自动选中并分割学员手里正在使用的整把打孔器。桌面上静止的相似钳子不能被当成目标。孔位选择和清理判定不在本次实现范围内；本次只解决可靠的器具掩膜，为后续孔盘局部分析提供输入。

## 已知问题

- 全画面文本提示会优先分割轮廓更清楚的静止钳子。
- 只框孔盘时目标过小，SAM3 不输出掩膜；扩大框后容易转而分割绿色橡皮布。
- 当前自动多孔圆盘定位已经能找到手持打孔器前端，可作为无需人工标注的空间锚点。

## 主方案

1. 在 CP02 采样帧中使用现有多孔圆盘定位器，选择孔盘清晰且运动可信的种子帧。
2. 以孔盘为锚点，在种子帧的运动区域和低绿色区域内寻找与孔盘相连的银色、细长器具主体。
3. 根据孔盘和器具主体自动生成覆盖整把手持打孔器的紧凑框，避免纳入桌面上的静止钳子。
4. 将自动框作为 SAM3 box prompt，从种子帧向前、向后分别传播，并合并同一对象的轨迹。
5. 对每帧掩膜执行语义保护，只有同时满足以下条件才可接受：
   - 掩膜包含或紧邻自动孔盘中心；
   - 掩膜主要位于自动器具框内；
   - 掩膜不是大块绿色区域；
   - 掩膜具有器具所需的细长形态；
   - 轨迹与手持孔盘共同运动，而不是长期静止在桌面上。
6. 保存种子帧、孔盘位置、自动器具框、逐帧掩膜、overlay、数值特征和拒绝原因。

## 后备顺序

主方案没有得到合格掩膜时：

1. 以自动跟踪的孔盘为中心生成局部裁剪视频，排除桌面静止钳子，再在局部画面使用简洁文本提示分割整把打孔器，并将掩膜映射回原图。
2. 局部 SAM3 仍失败时，才使用运动、金属外观和细长形态组成的确定性分割作为后备；后备结果必须带独立来源标记，不能伪装成 SAM3 结果。

## 输出状态

- `segmentation_passed`：连续多帧得到符合语义保护的手持打孔器掩膜。
- `segmentation_failed`：SAM3 有输出但被语义保护拒绝，记录具体原因。
- `not_observed`：阶段中没有可靠定位到正在使用的多孔圆盘。
- `needs_review`：定位或轨迹存在冲突，证据不足以自动决定。

任何单纯的非空掩膜都不能视为成功。

## 必要验证

1. 单元测试：自动整把器具框覆盖孔盘与移动器具，同时排除相邻静止钳子和大块绿色区域。
2. 单元测试：语义保护拒绝绿色橡皮布、静止钳子和不包含孔盘锚点的掩膜。
3. 聚焦回归：CP02 定位、SAM3 box 双向传播和审计输出测试。
4. 真实 GPU：至少运行当前 success 与 failure 视频中的 CP02 阶段。
5. 人工目视检查输出 overlay，确认掩膜确实覆盖手持打孔器；不得仅凭面积或连续帧数宣称通过。

本轮为快速聚焦实现，不先运行与 CP02 无关的全仓库测试；若改动触及共享 SAM3 后端，则补跑该后端全部相关测试。
