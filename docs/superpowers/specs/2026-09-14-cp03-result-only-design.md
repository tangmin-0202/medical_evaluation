# CP03 单孔结果判定

用户已批准：当前视频单孔场景，仅评价打孔结果，不检查上下提拉，不依赖 CP01/CP02 分数或标记追踪。

## 实施状态

- features/cp03_hole.py：原始分辨率候选孔掩膜的面积、连通数、圆度、实心度、椭圆轴比和 ROI 截断检查。
- judges/cp03_hole.py：可靠无孔 incomplete；持续看不清 needs_review；可靠缺损、不圆或粘连 incorrect；相邻清晰帧全部满足 correct。
- scripts/run_early_cp_sam3_gate.py 增加 --checkpoint-id cp_03，仅分割绿色橡皮布并保留原图、掩膜和 overlay，不自动评分。
- 旧 judge_cp03 的动作路径保留为历史路径；新 Judge 不读取 punch_contact / released_from_tip / reverse_motion，尚未切换 runtime。

## 待真实视觉门槛验证后接入

1. 从打孔后 CP03 橡皮布扫描帧寻找单孔候选，不能把任意白色亮点、黑色笔迹或 SAM3 掩膜漏点当贯通孔。
2. 背景可白、蓝或其他颜色，不以孔内单一颜色判贯通；需检查原图边缘与相邻帧背景一致性。
3. 布需较平整、无遮挡；倾斜先校正。拉伸、褶皱、阴影或孔壁分辨率不足不判断不圆。
4. 将完整性、圆形和残片连接证据转换为可靠布尔特征；实心度和圆度仅是几何量，不足以独立证明无粘连。
5. 寻找相邻清晰帧一致证据后提前结束阳性搜索；确认无孔必须覆盖可靠打孔后窗口。
6. 连续帧质量冲突时复核，不只选择最圆的一帧；保存数值、阈值、原因码和原始 ROI。
7. 新 extractor/runtime、实际候选孔检测、跨帧一致性、提前结束扫描和真实参数校准尚未完成，不能称为完整自动 CP03。

## 服务器实验

先查空闲 GPU，按 early-cp runbook 的命令换用 --checkpoint-id cp_03 和全新输出目录。
示例输出 data/runs/cp03-dam-object-gate-first。
单元测试中的圆度/尺寸/帧数仅为测试输入；尚未证明三个视频的实际孔能被可靠识别。
GPU 忙时暂停实测；不使用样本名称作为状态真值，也不把评估数增加到 6/11。
