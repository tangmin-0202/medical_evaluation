# CP02 最后可见打孔前状态判定

状态：2026-09-18 用户确认。本文覆盖旧 CP02 设计中“打孔后清理接触与残留消失”门槛；不改变其他考核点。

## 判定语义

1. 找到实际压下打孔动作之前、孔口仍可见的最后几帧。学员中途试对准或短暂遮挡不能充当最终打孔位置；打孔后冲柱遮挡也不能反推选孔。
2. 在这些帧内自动定位孔盘、孔径和冲柱，取最后连续稳定的对孔状态。目标是同一孔盘上按孔径从大到小第二大的孔，不按画面左右顺序。
3. 最终选错孔直接 `incorrect/wrong_punch_hole_selected`，不再进入绿色检查。
4. 最终选对时，只检查**该第二大孔的内部**在同一打孔前尾段是否呈橡皮布绿色。可靠绿色表示仍有残留，直接 `incorrect/residue_not_cleaned`；可靠非绿色表示已清理或本来没有残留，`correct`。不要求证明清理动作，也不看打孔后的绿色消失。
5. 如果实际打孔前尾段、孔径排序、冲柱对准、孔内可见性或颜色参照不可靠，返回 `needs_review`，不能把遮挡、手套、反光、旁边绿色背景或检测空值当成确定性结论。

## 最短 OpenCV 数据流

1. 用 CP02 阶段时间定位实际下压/接触事件；如果事件跨过标注的阶段边界，继续扫描到实际事件或下一阶段操作明显开始为止。保存原帧、时间和候选事件证据。不能仅凭“孔盘检测器消失”宣称已接触；找不到实际事件时不以试对准画面代替，返回 `needs_review`。
2. 从事件前向后选最后连续的、孔口无遮挡清晰帧；在原帧局部估计孔盘平面、各孔直径和冲柱轴线/端点。只需这段尾部证据，不默认追踪全阶段旋转。
3. 对最后稳定对孔至少使用两个不同源帧，保留孔径表、排名置信度、冲柱到孔中心距离、稳定时段及拒绝原因。若最后帧有遮挡，向前寻找最近的可见尾段，但必须排除之后又调孔或试对准的可能。
4. 仅在可靠选对后计算目标孔保守内圈的绿色比例；用同帧橡皮布作绿色参照，并拒绝孔内亮/暗遮挡。取尾段多帧一致结果。
5. 确定性 Judge 独占状态/原因码/分数；Qwen 只解释证据。每条路径（含 `needs_review`）保存原图、叠加图、数值和原因。

## 验收

- 测试先行：中途正确但最后选错；试对准遮挡后再调孔；最终可见对准；目标孔绿色/非绿色；邻近背景绿色；颜色遮挡或边界不可靠；打孔后重现。
- 本地聚焦测试、完整测试与 Ruff；真实 success、failure、clamp_failure 三视频按当前代码运行并目视核验尾段图，不按文件名强制标签。
- 只有真实视频能证明实际打孔前最终可见状态，且审计与证据完整时，才称 CP02 完成。否则保留 `needs_review` 并记录具体缺口。
