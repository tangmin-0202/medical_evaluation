# CP02 第二大孔与残留清理

用户确认：目标为孔径从大到小第二个孔，不按屏幕横坐标编号。
success 无需清理，failure 有清理但选孔错误，仅作为验收预期，不输入标签评分。

已实现独立 Hole 几何、可靠布局下第二大孔排序、唯一冲针对孔候选、同帧橡皮布颜色比例，以及独立 Judge。
输入孔半径需要同一度量平面校正，不能直接比较透视椭圆的屏幕直径。
选孔取最后调整到实际打孔之间的可靠连续帧，不把途中经过目标孔视为选择正确。
选错孔直接 incorrect；可靠选对且无残留 correct；有残留必须对同一孔清理并确认残留消失。
孔径排序、选孔关系或清理结果不可靠 needs_review；可靠阶段没有打孔动作 incomplete。

未完成：实际孔盘/孔洞检测、冲针与清理工作端定位、旋转身份追踪、连续动作窗口、颜色与残留阈值校准、extractor/runtime 接入及 GPU 视觉验收。
本模块不自动激活正式评分，不能称为完整 CP02 管线。测试中的尺寸、容差和颜色阈值是合成测试输入，不是已校准真实参数。
