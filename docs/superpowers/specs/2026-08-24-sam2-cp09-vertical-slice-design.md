# SAM2 CP09 支架分割纵向切片设计

## 目标

在不改变当前 `fake` 网页流程的前提下，用成功视频的 CP09（175–195 秒）和已审核的 `rubber_dam_frame` 提示，完成一条可审计的真实链路：读取标注、运行 SAM2、双向跟踪支架、生成掩膜叠加图、计算支架中心偏移，并交给现有 CP09 Judge 判定。

第一阶段只验证成功视频 CP09，不宣称已经完成 11 项真实评分，也不把单视频结果当成准确率。

## 当前缺口

现有 `Sam2Backend`、纯掩膜特征函数和 CP09 Judge 已存在，但尚未形成真实闭环：

- 同一对象、同一帧的多个点被逐次提交；SAM2 默认会清除旧点，可能只保留最后一个点；
- 当前只调用正向传播，提示位于区间后段时无法覆盖更早帧；
- 缺少读取标注、调用分割器、计算 CP09 特征并写证据图的具体 `FeatureExtractor`；
- `run_server.py` 不会根据模型配置构造真实分析管线；第一阶段不修改这一行为。

## 范围

### 包含

- 将标注 JSON 的点、框转换为统一 `SegmentationPrompt`；
- 按 `(object_id, frame_index)` 合并同帧多点，并一次性提交点数组和标签数组；
- 对所选时间段执行正向与反向传播，按帧去重，只输出区间内采样帧；
- 为 CP09 提取 `rubber_dam_frame` 掩膜；
- 计算每帧支架掩膜外接框中心相对画面中心的归一化距离，并使用有效帧中位数作为 `frame_center_offset`；
- 输出关键帧原图、布尔掩膜、彩色叠加图和特征 JSON；
- 提供独立命令行烟雾测试，在 GPU 服务器上运行成功视频 CP09；
- 使用假预测器完成 CPU 单元测试，不要求本地安装 SAM2 或 CUDA。

### 不包含

- 其他 10 个考核点的真实特征；
- Qwen/VLM 点评；
- 自动时间定位；
- 网页 `real` 模式切换；
- 阈值校准或三视频一致率计算；
- 修改人工标注、原视频或 Excel。

## 组件设计

### 1. 标注提示转换

新增一个纯转换函数，从 `VideoAnnotations.prompts` 中筛选目标对象和时间范围，将点转换为 `[x, y]`，将框转换为 `[x1, y1, x2, y2]`。对象名称严格使用清理后的 `rubber_dam_frame`。

转换层保留归一化坐标；像素换算仍由 `Sam2Backend` 根据实际视频宽高完成。区间内没有目标提示时立即报出包含视频、考核点和对象名的错误。

### 2. SAM2 多点与双向传播

`Sam2Backend` 在同一对象、同一帧上批量提交所有正负点，避免默认 `clear_old_points=True` 覆盖旧点。框必须先于修正点提交；同帧同时存在框和点时，合并为一次调用。

从提示帧分别向时间增大和时间减小方向传播。结果按 `frame_index` 合并；提示帧或双向传播重复返回时只保留一份。最后应用 `sample_fps` 和 CP09 时间范围过滤。若所安装的官方 SAM2 版本不支持反向传播参数，烟雾测试必须明确失败并显示版本/提交信息，不静默退化成单向结果。

### 3. CP09 特征提取

对每个有效支架掩膜计算非零区域外接框的中心 `(cx, cy)`。支架是中空的杆状结构，外接框中心比掩膜质心更接近临床上所说的“支架是否居中”。中心偏移定义为：

```text
sqrt(((cx - W/2) / W)^2 + ((cy - H/2) / H)^2)
```

区间特征取所有有效采样帧偏移的中位数，以降低手部短时遮挡造成的异常值影响。没有有效掩膜时返回 `None`，由现有 Judge 输出 `needs_review`，不能把缺失证据当成错误或正确。

### 4. 证据与产物

烟雾测试输出到 `data/runs/smoke-cp09-<timestamp>/`，只包含派生结果：

- `summary.json`：视频、区间、提示数量、SAM2 版本、有效帧数量和中心偏移；
- `frames/`：选定关键帧；
- `masks/`：单通道支架掩膜；
- `overlays/`：稳定颜色叠加图，带对象名和时间；
- `decision.json`：现有 CP09 Judge 的状态、理由和匹配规则。

所有输出路径必须验证位于 `data/runs` 下。烟雾测试不得覆盖标注 JSON。

## 命令行接口

新增 `scripts/smoke_sam2_cp09.py`，主要参数为：

```text
--video-id success
--checkpoint cp_09
--backend sam2
--checkpoint-path <sam2.1 checkpoint>
--model-config configs/sam2.1/sam2.1_hiera_l.yaml
--device cuda:0
--sample-fps 2
```

脚本从项目配置和 `data/annotations/success.json` 获取其余信息。第一阶段固定只接受 `success/cp_09`，防止误以为已经支持其他组合。

## 错误处理与审计

- 缺少视频、标注、模型权重或目标提示：启动前失败；
- 提示时间不在视频范围：报告具体提示；
- SAM2 版本不兼容：显示实际安装提交和缺失接口；
- CUDA OOM：释放缓存后以更低采样率重试一次，并写入 `summary.json`；第二次失败则终止；
- 有效掩膜过少：判为 `needs_review`，不生成确定性分数；
- 输出记录模型配置、checkpoint SHA-256 前 12 位、设备、采样率和运行时间。

## 测试策略

CPU 测试使用假预测器验证：

- 同帧五个支架点作为一个批次提交；
- 正向和反向结果合并且帧不重复；
- 只返回 175–195 秒且满足采样步长的帧；
- 空掩膜得到 `frame_center_offset=None`；
- 已知居中/偏移掩膜得到正确的归一化距离和中位数；
- 证据只能写入指定运行目录；
- 不安装 SAM2 时，普通单元测试仍可运行。

GPU 验收只针对成功视频 CP09：命令退出码为 0，生成非空掩膜和叠加图，`summary.json` 记录有效帧数，人工查看至少三张分布于区间前、中、后的叠加图。只有人工确认掩膜确实覆盖支架后，才进入网页真实管线与其他考核点。

## 实施顺序

1. 先用测试固定多点批处理和双向传播行为；
2. 修正 `Sam2Backend`；
3. 实现提示转换和 CP09 特征提取；
4. 实现独立烟雾测试与证据输出；
5. 本地运行完整 CPU 测试；
6. 推送代码，在 GPU 服务器安装官方 SAM2 和权重；
7. 运行成功视频 CP09，人工审查叠加图；
8. 验收通过后另行设计真实网页管线和其余考核点。
