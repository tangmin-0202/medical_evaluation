# SAM2 至 SAM3 项目汇报材料设计

## 文档定位

输出一份可直接用于阶段性项目汇报的 Word 文档，面向指导教师、项目成员及评审人员。材料重点说明项目已经完成的工作、真实运行结果、SAM2 路线遇到的关键困难，以及下一阶段迁移 SAM3 的必要性。正文控制在约 4–6 页，不写成代码手册或完整技术交接文件。

## 核心表述

- 已跑通的纵向链路为：阶段抽帧、SAM2 分割与跟踪、特征提取、确定性规则判定、阶段性评分、本地 Qwen3-VL 点评和网页报告。
- 当前真实自动评价范围只有 CP09 和 CP11；其余项目尚未完成，阶段性结果不能表述为正式总分或模型泛化准确率。
- SAM2 并非完全不可使用。它已经验证了整体工程路线，并继续保留为基线与回退后端。
- 迁移的核心原因是 SAM2 属于提示驱动分割模型，依赖人工点或框，不能稳定完成新学员视频中的开放语义对象发现；这使 CP01 的笔、黑点以及 CP11 的橡皮布等对象难以实现真正自动化。
- SAM3 的价值需要通过官方实现、真实 GPU 推理和同视频对照实验验证，文档不得声称 SAM3 已经接入或必然优于 SAM2。

## 内容结构

1. 项目背景与目标：说明橡皮障隔离术视频智能考核需求，以及可解释、可复核的设计原则。
2. 已完成工作：概述网页标注、窗口化抽帧、SAM2、CP09/CP11 Judge、阶段性评分和 Qwen 点评。
3. 实际达到的结果：列出三条样例视频的 CP09/CP11 真实运行结论，并明确样本规模限制。
4. SAM2 实施中的困难：说明显存问题及解决、坐标错误、人工提示依赖、CP01 暗点干扰、CP11 颜色规则脆弱等。
5. 迁移 SAM3 的理由：围绕语义发现、减少人工提示和扩展其他考核点，不夸大未验证能力。
6. 下一步计划：独立环境验证 SAM3，保持 Judge、评分和 Qwen 不变，先对 CP09/CP11 做同数据对照，再扩展其他 CP。

## 版式设计

- 采用正式、简洁的项目汇报风格，包含封面、正文和简短结论。
- 使用一张端到端流程图展示数据流，使用一张对比表说明 SAM2 当前能力、限制和 SAM3 迁移目标。
- 真实结果采用紧凑表格；技术困难采用短段落或项目符号，避免大段代码、命令和过多参数。
- 视觉风格以深蓝为主色，正文保持高可读性，页眉或页脚显示项目简称及页码。

## 数据与准确性约束

- 使用当前仓库及 2026-09-03 交接说明中已经确认的数据。
- 明确区分“流程已跑通”“两个考核点已实现”“完整系统已完成”三个层级。
- 三个样例视频只作为功能验证，不报告准确率、灵敏度或泛化结论。
- CP09 失败视频仍可能在“支架居中”这一单项获得正确结论，不能用上游失败标签覆盖该项几何事实。
- Qwen 只生成证据点评，不能修改 Judge 状态和分数。

## 交付与检查

交付文件为一个 `.docx`。生成后必须完成内容核对、结构检查、DOCX 页面渲染及逐页目视检查，确认中文字体、流程图、表格、分页、页眉页脚和页码不存在缺失、截断或重叠。
