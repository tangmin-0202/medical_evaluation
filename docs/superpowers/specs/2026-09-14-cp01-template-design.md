# CP01 模板板定位设计与实施状态

用户确认：白色面板置于橡皮布下方，目标为面板正向时右下牙弓从上往下第三点。
截图红圈仅用于定义规则，不读取圈选坐标、人工对象点框或历史参考 u/v。

## 已实现的独立模块

- features/cp01_template.py：校正板面小黑点候选检测、可靠方向和完整布局约束下目标点排序、当前帧投影、已配准画面的新增暗色候选、按相邻点距归一化标记距离。
- judges/cp01_template.py：可靠阶段无笔尖接触为 incomplete；参考/新增笔迹不可靠为 needs_review；可靠无新增笔迹或偏离目标为 incorrect；目标标记符合允许距离为 correct，额外标记不扣分。

这些低层函数不自行证明面板朝向或点位完整性。禁止调用方以“找到三个点”设定 layout_complete=True。
黑点检测当前使用候选颜色和形状，文字小笔画可能混入，必须在真实点阵布局校验后才能使用。
新增暗色候选不是已确认墨迹：需要排除阴影、手笔遮挡、布板相对滑动，并检查持续性或布离板证据。
原始中心线未必正好位于边框中心；调用前必须以印刷中心线校正坐标，不能仅按板面四角归一化。
