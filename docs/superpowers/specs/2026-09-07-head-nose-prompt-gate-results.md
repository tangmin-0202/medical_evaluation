## 目视结论

头模的自动结构门槛也不能作为最终通过结论。三张头模候选联系表和对应二值掩膜显示：

- failure 与 clamp_failure 在无遮挡时通常能覆盖绿色头模外壳主体；
- success 在橡皮布覆盖和手部操作时，掩膜经常只保留暴露的绿色底座、零散弧形区域或支架附近区域；
- 同一阶段内轮廓范围发生明显变化，不能稳定代表完整头面部，也不足以可靠建立中心、尺度与主方向；
- 三个候选表现相近，没有一个满足“遮挡下仍可建立连续头模坐标系”的目视验收条件。

所以第一轮真实结论是：**鼻部直接文本分割没有通过；头模语义分割可用，但不能直接用掩膜质心、外接框或 PCA 建立姿态。** 用户随后目视确认头模分割目标本身正确，因此恢复后的实验改为使用头模掩膜约束模板配准，而不是继续要求可见掩膜本身具有稳定中心和主方向。

## 恢复后的下一步

恢复研发时从这里继续，不重跑已经完成的 27 个第一轮会话，不开始 CP09/CP11 Judge 改造。先做最小的第二轮可行性实验：

1. 复用本轮保存的原始帧和头模掩膜，不重跑 27 个 SAM3 会话。
2. 用头模掩膜限定有效区域，验证同型号头模的版本化相似变换配准，并通过同一变换映射鼻部模板和支架区域。
3. 门槛检查配准残差、轮廓重叠、尺度/角度范围和连续帧跳变，并保留目视否决。
4. 只有映射后的鼻部和支架区域在三个视频连续帧均可靠时，才改造生产 CP09/CP11 提取器与 Judge。

后续获批的详细设计和实施计划分别见 `2026-09-08-cp09-cp11-template-registration-design.md` 与 `../plans/2026-09-08-cp09-cp11-template-registration.md`。

三个样本仍只证明 Demo 分支行为，不能用于准确率或泛化结论。
