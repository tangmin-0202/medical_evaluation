## 目视结论

头模的自动结构门槛也不能作为最终通过结论。三张头模候选联系表和对应二值掩膜显示：

- failure 与 clamp_failure 在无遮挡时通常能覆盖绿色头模外壳主体；
- success 在橡皮布覆盖和手部操作时，掩膜经常只保留暴露的绿色底座、零散弧形区域或支架附近区域；
- 同一阶段内轮廓范围发生明显变化，不能稳定代表完整头面部，也不足以可靠建立中心、尺度与主方向；
- 三个候选表现相近，没有一个满足“遮挡下仍可建立连续头模坐标系”的目视验收条件。

所以第一轮真实结论是：**现有文本 prompt 组合下，头模坐标方案和鼻部直接文本分割均未通过生产实现门槛。** 不能因为非空掩膜比例通过就开始改 Judge，也不能恢复人工口腔/鼻部框并声称全自动。

## 恢复后的下一步

恢复研发时从这里继续，不重跑已经完成的 27 个第一轮会话，不开始 CP09/CP11 Judge 改造。先做最小的第二轮可行性实验：

1. 基于当前原图和失败掩膜，测试更贴合实体外观的局部参照目标；优先考虑稳定的绿色头模外壳轮廓、鼻部周围固定塑料区域或颜色/几何鼻部定位，不扩大到开放式无限 prompt 搜索。
2. 对鼻部先判断 SAM3 文本能力边界；若小目标始终零输出，转为“稳定头模外壳 + 同型号头模的版本化鼻部相对模板”，并明确这是设备模板定位而非鼻部语义分割。
3. 修改自动门槛，使头模除了连续非空和最大连通域比例，还必须检查面积、中心、尺度和方向的时序稳定性，并保留目视否决。
4. 只有新的头模参考与鼻部定位在三个视频连续帧均通过后，才执行实施计划 Task 2 及后续生产代码。

三个样本仍只证明 Demo 分支行为，不能用于准确率或泛化结论。
