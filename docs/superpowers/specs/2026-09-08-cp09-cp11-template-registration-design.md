# CP09/CP11 头模模板配准设计

## 决策

本设计修订 2026-09-07 的头模相对坐标方案。第一轮真实实验已经证明头模文本提示能够产生用户目视认可的语义掩膜，但掩膜可见范围随遮挡变化，不能直接用质心、外接框或 PCA 主轴定义姿态；鼻部文本提示在三个视频中全部零输出。

因此生产方案采用头模模板配准。SAM3 头模掩膜只限定配准区域和验证轮廓，不直接产生中心、尺度和方向。鼻部不再单独分割，而是从同型号头模的版本化模板映射一个鼻部呼吸区域。

## 配准模型

同一阶段及 CP09 到 CP11 的拍摄机位和头模姿态基本固定。首版只估计四自由度二维相似变换：平移、旋转和统一缩放，不引入自由度更高的透视变换。

模板包含一张清晰参考帧、参考头模掩膜、鼻部多边形和版本信息。当前帧先用 SAM3 头模掩膜限定有效区域，再用掩膜轮廓距离和区域内图像结构估计相似变换。连续帧以上一帧变换作为初值。每个结果保存匹配内点数、轮廓重叠、配准残差、尺度和角度；未达到质量门槛的帧不能进入特征聚合。

若模板到当前帧的变换为 `M_t`，模板坐标点 `q` 在当前帧的位置为 `p_t = M_t q`。CP09 实际支架掩膜先用 `M_09^-1` 转换并保存为模板坐标多边形；CP11 再用 `M_11` 投影，组合映射为 `M_11 M_09^-1`。这不是跨阶段逐帧追踪，不会累计 CP09 到 CP11 的遮挡误差。

## 一次性设备模板

同型号头模只校准一次，不为每个视频重新标注。模板鼻部区域采用用户确认的鼻背斜面和鼻孔周围呼吸区域，明确排除口部。初始模板可从 success 清晰帧建立，必须记录源视频、时间、图像尺寸、代码提交、SAM3 版本和 `demo_only: true`。

模板只能用于同型号头模和相近拍摄协议。模板版本不匹配或配准质量不足时返回人工复核，不能用固定全图坐标强行判定。

## CP09

1. 在完整 CP09 内分别运行头模和白色 U 形支架 SAM3 会话。
2. 对头模连续帧执行模板配准，并把支架掩膜转换到模板坐标。
3. 在阶段后部寻找至少两秒的稳定窗口，检查支架存在性以及模板坐标中的中心、角度和尺度变化。
4. 将稳定窗口的实际支架区域保存为当前视频参考，即使位置不合格也保存真实区域供 CP11 使用。
5. 依次区分 `unreliable_head_registration`、`frame_not_observed`、`frame_missing_at_stage_end`、`frame_not_stabilized`、`frame_installation_failed` 和 `criteria_satisfied`。

## CP11

1. 全阶段绿色规则只区分橡皮布从未出现和出现后末尾消失。
2. 阶段后部只运行头模和橡皮布两个 SAM3 会话，不再运行鼻部会话，也不从 CP09 长程追踪支架。
3. 通过 CP11 头模配准映射模板鼻部区域。
4. 优先读取当前视频 CP09 的实际支架模板区域；缺失时才使用版本化标准支架区域，并记录来源。
5. 计算橡皮布与鼻部区域的重叠率、预期支架区域覆盖率及其中白色裸露比例。
6. 支架区域被覆盖且鼻部无遮挡时为 `correct/criteria_satisfied`；配准不可靠时为 `needs_review/unreliable_head_registration`。

CP11 删除整帧 `dam_area_ratio` 判据。口部本应被橡皮布覆盖，不进入无遮挡判定。

## 最小门槛与实施顺序

生产改造前先复用 2026-09-07 已保存的原始帧和头模掩膜，不重复 27 个 SAM3 会话：

1. 用合成图验证相似变换、逆变换、掩膜映射和质量门。
2. 建立一版 success 头模模板和鼻部区域。
3. 在三个视频 CP09/CP11 的连续代表帧上生成配准叠加图。
4. 目视确认鼻部区域落在真实鼻部、投影轨迹连续，并且坏配准会被质量门拒绝。
5. 门槛通过后才替换 CP09/CP11 提取器和 Judge；失败时保留证据，先定位配准失败来源再调整。

## 验证

- 所有新函数按失败测试、最小实现、回归的顺序开发。
- 本地运行聚焦测试、完整 pytest 和 Ruff。
- 服务器运行实际环境聚焦测试与三个样本的完整 GPU 管线。
- 每个有视觉证据的样本目视检查 CP09/CP11 叠加图、稳定窗口、映射鼻部和支架区域。
- 最后恢复 Qwen，核验报告证据路径、原因码、已评估 `2/11`、阶段性分数和 `final_score=null`。

三个样本只证明 Demo 链路和判定分支可运行，不表示准确率或泛化能力。
