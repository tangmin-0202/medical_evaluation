# CP01 and CP11 Parallel Slices Implementation Plan

> **Confirmed implementation correction:** The manual student `mark` contract below is superseded. Only the expert `success` video receives one `cp01_reference` point; learner marks are detected across the complete CP01 stage and selected only after stage end. One stable point is the punch; with two points, exactly one dam-local corner point is discarded as auxiliary; all other multi-point sets require review. CP01 and CP11 are run through `scripts/smoke_sam2_cp01_cp11.py` in one SAM2-loaded job and one result directory.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build independently testable CP01 and CP11 real-evaluation slices, collect the exact prompts from all three videos, and produce calibrated decisions and visual evidence.

**Architecture:** CP01 is a CPU-only single-frame geometry extractor that compares the student's mark in rubber-dam-local normalized coordinates with one calibrated reference coordinate. CP11 first uses a deterministic whole-stage green-dam presence check to return `incomplete` when the step never happens, then uses SAM2 and appearance filtering over the final three seconds to measure dam area, nose overlap, and visibly exposed frame area. Both slices retain separate extractors and smoke entry points while reusing annotation, video, evidence, and Judge contracts.

**Tech Stack:** Python 3.11, Pydantic, OpenCV, NumPy, SAM2.1, FastAPI/Jinja/vanilla JavaScript, pytest, Ruff, Git bundle.
